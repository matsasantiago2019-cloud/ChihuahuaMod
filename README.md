# Chihuahua Mod — Forge 26.3
Minecraft Java 26.3 · Forge 66.1.5 · Java 25

## Incluye
- Entidad Chihuahua domesticable que hereda comportamiento de lobo: huesos, seguimiento, sentarse, defensa, reproducción y collar.
- Entidad de tamaño reducido.
- Textura pixel-art propia de pelaje canela/crema, orejas oscuras y arnés rojo.
- Huevo generador disponible en la pestaña Huevos de aparición.
- Registro de ubicación de aparición en superficie.
- Comando de prueba: `/summon chihuahuamod:chihuahua`.

## Instalación
Instala Forge 26.3-66.1.5 y copia `ChihuahuaMod-1.0.0.jar` a `.minecraft/mods`.

## Limitaciones visuales
El renderizado usa la geometría de lobo de Minecraft como base, con la textura de Chihuahua del proyecto; todavía no es un modelo geométrico exclusivo. El aspecto de la textura es una interpretación pixel-art y no un calco de la foto original.
